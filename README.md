# ⚡ FlowInventory

**Smart AI-style inventory management for Minecraft 1.20.1**

> Stop wasting time sorting. Start playing.

---

## ✨ What makes FlowInventory different?

Most inventory mods just sort items alphabetically or by type.

**FlowInventory learns how YOU play.**

It detects your current activity (⛏ Mining, ⚔ Combat, 🧱 Building, 🌾 Farming) and:
- **Auto-organizes** your inventory with your most-used items first
- **Swaps your hotbar** to the right tools automatically
- **Learns over time** — the more you play, the smarter it gets

---

## 🎮 Features

| Feature | Description |
|---|---|
| **Smart Sort** (R key) | Sorts inventory using AI pattern data — most-used items first |
| **Activity Detection** | Detects Mining/Combat/Building/Farming from your held item + surroundings |
| **Auto Hotbar Swap** | Switches hotbar layout automatically when activity changes |
| **Profile System** | Save custom hotbar layouts per activity |
| **Manual Cycle** (G key) | Manually switch between activity profiles |
| **Settings GUI** (J key) | Full in-game settings and profile management |
| **HUD Overlay** | See your current activity in the corner of your screen |
| **Pattern Learning** | Tracks item usage to improve sorting over time |

---

## ⌨️ Keybinds

| Key | Action |
|---|---|
| `R` | Sort inventory (main inventory, not hotbar) |
| `G` | Cycle to next activity profile |
| `J` | Open FlowInventory settings |

All keybinds can be rebound in **Options → Controls → FlowInventory**

---

## 🔧 Installation

1. Install [Fabric Loader](https://fabricmc.net/use/) for Minecraft 1.20.1
2. Install [Fabric API](https://modrinth.com/mod/fabric-api)
3. Download FlowInventory and place in your `mods` folder
4. Launch Minecraft — done!

**Optional:** Install [Mod Menu](https://modrinth.com/mod/modmenu) to access settings from the main menu.

## 🤝 Compatibility

- ✅ Just Enough Items (JEI)
