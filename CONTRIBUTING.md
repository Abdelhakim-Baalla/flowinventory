# Contributing

Thanks for helping improve **FlowInventory**.

1. **Fork** [`Abdelhakim-Baalla/flowinventory`](https://github.com/Abdelhakim-Baalla/flowinventory) and create a branch from `main` (or `develop` if the project uses it for integration).
2. **Build:** from the repo root run `./gradlew build` (Java **21**).
3. **Scope:** keep changes focused on one fix or feature; match existing code style.
4. **Pull request:** describe *what* changed and *why*; link issues if any.

Do **not** commit:

- Personal paths (`C:\Users\...`), API tokens, CurseForge/Modrinth secrets — use ignored local files under `docs/LOCAL/` (see `paths.example.md`).
